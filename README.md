# Neural Network From Scratch

This repository contains my learning exercises while studying the fundamentals of Artificial Neural Networks (ANNs) in Python.

The goal is to understand how neural networks work internally by implementing the main concepts from scratch, without using machine learning frameworks such as TensorFlow or PyTorch.

## Topics Covered

So far, this repository includes exercises about:

- Artificial neurons
- Inputs
- Weights
- Bias
- Activation functions
- ReLU
- Sigmoid
- Hidden layers
- Output layers
- Forward propagation

Future topics will include:

- Loss functions
- Gradient descent
- Derivatives
- Backpropagation
- Weight and bias updates
- Neural network training
